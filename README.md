# Cora Privacy Policy

This repository hosts the privacy policy for the Cora mobile app.

## View the Privacy Policy

The privacy policy is available at: `privacy-policy.html`

Once this repository is published to GitHub Pages, the privacy policy will be accessible at:
`https://YOUR-USERNAME.github.io/cora-privacy-policy/privacy-policy.html`

## Setup Instructions

1. Create a new repository on GitHub named `cora-privacy-policy`
2. Upload the `privacy-policy.html` file to the repository
3. Go to Settings → Pages
4. Select "Deploy from a branch" → "main" branch → "/ (root)"
5. Save and wait 1-2 minutes
6. Your privacy policy will be live!
